Things the tree alone will not tell you:

- **The asset handler's missing single-page fallback is load-bearing, not an oversight.** The dashboard has no router, so any path that is not the root or an embedded file is a 404 — and that is precisely what makes the status listener answer 404 for `/report/*`, which is the listener-isolation acceptance condition from the status side. Adding an index fallback "for SPA routes" would silently convert that 404 into a 200 and void the guarantee while every other test still passed.

- **API tests decode with the contract's own generated decoder, not `dd`.** Strict `df/dd` binding rejects JSON `null` for typed pointers (the same gotcha stage 2 hit on the state file), and three status fields are required-and-nullable by design. `api.Status.Decode(jx.DecodeBytes(...))` reads the document exactly as a generated client would; the explicit-null assertions are raw-substring checks beside it, because a decoder cannot distinguish an absent key from a null one.

- **The model and contract vocabularies are converted by direct string cast, held safe only by a test.** `describeCheck` casts `model.Kind`/`model.State` straight into `api.Kind`/`api.State`; `TestContractEnumerationsMatchTheModel` is what pins the two enumerations equal. If the spec's enum order or values ever change, that test is the thing that catches it — do not delete it as redundant.

- **Deliberate non-action: the two listeners' `Run`/shutdown code was left duplicated.** `internal/server/server.go` closely mirrors `internal/ingest/server.go`, and extracting a shared helper is explicitly sanctioned by the listener-isolation quality. It was not done because the ingest constructor carries the loopback verification Michael installed after stage 4's blocking finding, and putting that lock back into a refactor buys nothing functional.

- **ogen is pinned to v1.23.0 in both the `go:generate` directive and `go.mod`.** Reckon and ranger generate with 1.20.3 while carrying a newer runtime; keeping generator and runtime in lockstep here is deliberate, and a bump should move both together.

- **Time-in-state on the page is measured against the document's own `generated` stamp, never the browser clock.** That carries the injected-clock discipline through to the render and explains why the elapsed column freezes while the stale banner is up: the page is reporting the last status it actually received, not guessing forward.

Configured Terminus round `d03482c3c41d` returned two blocking findings, both taken:

- **ogen's OpenTelemetry integration is disabled through `internal/api/ogen.yml`.** The generated handlers wrapped every request in a `time.Now`/`time.Since` stopwatch inside `internal/`, which the injected-clock rule does not allow. Disabling the feature is also the right call on its own terms — instrumentation machinery does not belong in a project whose spec defers metrics permanently — and it drops the OpenTelemetry modules from `go.mod`. Note that switching the feature off while the otel-only `oas_labeler_gen.go` still existed made that one generate run fail; a second run from the cleaned tree succeeds, and generation is reproducible from here.

- **The asset handler resolves the path before it polices the method.** It previously answered 405 to a POST for a path it does not serve, which let a verb reveal that some other surface owns the path; the isolation guarantee is about the path, not the verb. The cross-surface test had hedged by accepting either 404 or 405 — that hedge is exactly what the quality warns against, and it now requires 404 across four methods.
